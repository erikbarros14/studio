# **App Name**: TrackFit Go

## Core Features:

- Run Tracker: Track running time, distance, and estimated calorie burn using device sensors.
- Stats Display: Display real-time stats and a summary of the run in a clear, intuitive interface.
- Run History: Allow users to save their runs and view past activity history.

## Style Guidelines:

- Primary color: Teal (#008080) to represent health and vitality.
- Secondary color: Light gray (#D3D3D3) for a clean and modern look.
- Accent: Orange (#FFA500) for highlighting important stats and CTAs.
- Clean, card-based layout for easy readability and navigation.
- Use modern, minimalist icons to represent different stats and actions.
- Subtle animations for transitions and user interactions to enhance the user experience.
