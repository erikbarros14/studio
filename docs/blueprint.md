# **App Name**: ImageScribe

## Core Features:

- Image Input: Allow users to upload images from their device or paste image URLs.
- Text Extraction: Use OCR (Optical Character Recognition) to extract text from the uploaded image. The AI is used as a tool to identify the text in the image.
- Text Output: Display the extracted text in a clear, editable text area. Users can copy the text to their clipboard.

## Style Guidelines:

- Dark background to create a modern, tech-focused aesthetic.
- Use a vibrant blue (#29ABE2) as the accent color to highlight key elements and calls to action.
- Clean and intuitive layout for easy navigation and usability.
- Use minimalist, line-based icons to complement the modern design.
