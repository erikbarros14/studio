# **App Name**: CalmWave

## Core Features:

- Empathetic Chatbot: Provides empathetic text-based responses using generative AI based on Cognitive Behavioral Therapy (CBT) principles.
- Sentiment Analysis: Real-time sentiment analysis of user input to adapt responses and offer appropriate support; a tool that chooses between multiple categories of sentiment.
- Emergency Kit: Offers a multi-modal emergency kit including contact information for professional help, guided breathing exercises, and grounding techniques (the grounding techniques are text only, without the image).
- Mood Tracking: Generates a real-time mood graph to visually represent emotional trends during the conversation.
- Voice Input: Allows users to optionally input via voice, transcribing to text for analysis and response.
- Audio Exercises: Provides relaxation exercises as an audio output, featuring nature sounds and a calming voice to ease anxiety.

## Style Guidelines:

- Primary color: Soft lavender (#B5B2FF) to evoke calmness and tranquility.
- Background color: Light gray (#F0F0F5) to provide a gentle, unobtrusive backdrop.
- Accent color: Muted blue (#75A1D0) to highlight interactive elements without overwhelming the user.
- Use clear and readable font to ensure easy interaction for all users.
- Use simple, calming icons for key features (e.g., a heartbeat for mood tracking, sound waves for audio exercises).
- Design a clean and minimal chat interface with an emphasis on readability and ease of use.
- Subtle, gentle animations to provide feedback and create a soothing experience (e.g., a soft glow around active buttons).
